Scope: the public one-page site on GitHub Pages; Persuade mode. Also hosts the working Shield lookup and Sift filter tools.

Audience and action: Agent ID holders arriving from X, mostly on phones. Primary action: paste an address and check it before signing. Secondary: run a list through Sift; learn how to report; follow Errands' build.
