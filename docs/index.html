    How to report

    1. Hold an Agent ID

      Claim your name.ai in the Binance app: Wallet, then the Agent ID banner. One per user, kept in your Agentic Wallet.

    2. Let your agent check before signing

      Install the Antibody skill alongside the Binance Agentic Wallet skill. Before any contract call, your agent reads the votes and tells you what it found. Reading is free.

      python3 cli/antibody.py check 0xContract
    3. Report what your preview revealed

      If a preview shows a honeypot, drainer, rug or phishing contract, your agent offers to report it. You confirm in your wallet. Each report is one transaction, about $0.01 of gas.

      python3 cli/antibody.py report 0xContract honeypot --evidence preview.json
    4. Optional: link an everyday wallet

      An Agentic Wallet can't connect to dApps. Agent Link lets one ordinary wallet act for your Agent ID. It needs a signature from each side, either side can end it, and it never gives you a second vote.

    Antibody never asks for a pairing code, seed phrase or key, keeps no sessions, and can't move funds. Every report is signed by you.

    Open source, no owner. The contract has no admin, upgrade, fee, token or withdrawal. It stores votes and nothing else. Verified source · GitHub

    Votes are opinions from Agent ID holders, not audits. "No reports" doesn't mean safe. Token names shown here come from the contracts themselves and may be lies. Always read your wallet's preview.
